# Security Policy

This file is the default security policy for all repositories under [@Gillellbor](https://github.com/Gillellbor). Individual repositories may override with their own `SECURITY.md`.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it **privately**. Do NOT open a public GitHub issue for security vulnerabilities.

### Preferred channels

1. **GitHub Private Vulnerability Reporting** — use the "Report a vulnerability" button in the Security tab of the affected repository.
2. **Email** — `security@hradni.net` (PGP key on request).

### Response commitment

I will acknowledge your report within **72 hours** and provide a more detailed response within **7 days** indicating the next steps.

## Supported Versions

These projects follow a rolling-release model. Only the latest release on `main` receives security updates.

## Scope

**In scope:** code and configuration in the reported repository.
**Out of scope:** third-party services, social engineering, physical security.

## Public disclosure

I will coordinate public disclosure with the reporter after a fix is shipped. Standard embargo: **90 days** unless mutually extended.

## Acknowledgements

Reporters of valid vulnerabilities will be credited in release notes unless they request anonymity.
